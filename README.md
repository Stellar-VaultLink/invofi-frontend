# invofi-frontend (archived)

This repository has been **archived**. InvoFi's frontend now lives at **`invofi/apps/frontend`** in the main [invofi](https://github.com/Stellar-VaultLink/invofi) monorepo, where Vercel deploys it straight out of that directory. All issues, PRs, and history from this repo were folded into the monorepo before archiving; no unique app code was lost.

See the [invofi](https://github.com/Stellar-VaultLink/invofi) repository for the current frontend, the [invofi-contracts](https://github.com/Stellar-VaultLink/invofi-contracts) repository for the Soroban smart contracts, and the [Project Map](https://github.com/Stellar-VaultLink/invofi#repositories) for how the two-repo topology fits together.
